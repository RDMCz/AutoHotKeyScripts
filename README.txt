These scripts are made with CZ keyboard layout in mind and may not work properly elsewhere

= HotDelphi.ahk =

* For personal use in Delphi IDE
* Notable hotkeys:
  * AltGr + O to duplicate current line
  * AltGr + ← to copy current line
  * AltGr + → to paste copied line
  * AltGr + ↑ to move current line up
  * AltGr + ↓ to move current line down

= MathNotes.ahk =

* Makes writing math notes in Markdown easier  
* Allows you to write symbols such as 𝑎, 𝑏, α, β, ₀, ₁, ⁰, ¹, ∀, ∃, ℝ, ℕ, etc.
